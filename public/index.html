An HTML to PDF API built for billing documents

Webhook recipes

Turn a Stripe, WooCommerce or form webhook into a branded PDF: map the payload to a gallery template and send it. See the recipes.

Works with no-code

Plain JSON over HTTPS, so it plugs into Zapier, Make, n8n and Bubble without a plugin. Set output:'url' to get a 24-hour download link instead of a file. No-code setup.

Bring your own HTML

Already have a Blade, Jinja or Django view? Send its rendered HTML with raw:true. No template rewrite.

Templates live server-side

Store templates once, then send only data. Change a layout without redeploying your app. Handlebars plus money, date and sum helpers built in.

Page numbers & QR codes

Add a footer_html with page X of Y on every page, and drop {{qr}} into a template for payment or verification links.

Your data stays yours

Request JSON and PDFs are rendered in memory and never stored unless you ask for a temporary download link. Each render runs in an isolated Chromium context with JavaScript disabled. Security details.

Pricing

Monthly, cancel anytime. Paid plans include a 10% grace buffer; past that, renders return HTTP 402 until next month or you upgrade. Template syntax errors and other failed requests are refunded; renders that time out, run too long or exceed your page limit count as one. Check usage with GET /v1/me or the X-Renders-Remaining header. Prices in USD; checkout and VAT handled by Lemon Squeezy (merchant of record).
