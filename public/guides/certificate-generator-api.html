Certificate generator API: one PDF per attendee

Course platforms, workshops and event organisers: POST a name and a course to gallery:certificate and get an A4 landscape certificate with a QR code that links to your verification page.

Landscape certificate for courses, workshops and events, with optional logo, signature images and a verification QR code.

Landscape and paper size

The template sets its own page in CSS (@page { size: A4 landscape; margin: 0 }) and ships with options {"landscape": true, "preferCSSPageSize": true} and a margin of 0, so the double frame sits exactly 14 mm from the paper edge. For US Letter, override both the format and the CSS preference in the request:

{
  "template_id": "gallery:certificate",
  "data": { "recipient": "Ayesha Khan", "course": "Practical Machine Learning", "date": "2026-10-15" },
  "options": { "format": "letter", "landscape": true, "preferCSSPageSize": false }
}

Verification QR codes

The qr helper renders a QR code as inline SVG, so it needs no network fetch and stays sharp at any zoom. The certificate uses {{qr verify_url size=72}}; size is in pixels, from 32 to 400, default 96. Point verify_url at a page on your own site that looks the certificate ID up, so a printed copy can be checked.

<div class="verify">{{qr verify_url size=72}}<br>Scan to verify</div>

Render it with curl

With no data, the API renders the sample above and sets X-DocForge-Sample-Data: true, which is a quick way to check your key:

Sample data
curl https://YOUR-DOMAIN/v1/render \
  -H "Authorization: Bearer $DOCFORGE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"template_id": "gallery:certificate"}' \
  -o certificate.pdf

With your own data, save the JSON above as sample.json and wrap it:

Your data
jq '{template_id: "gallery:certificate", filename: "certificate.pdf", data: .}' sample.json \
  | curl https://YOUR-DOMAIN/v1/render \
      -H "Authorization: Bearer $DOCFORGE_KEY" \
      -H "Content-Type: application/json" \
      --data-binary @- -o certificate.pdf -D headers.txt
grep -i x-renders-remaining headers.txt

Bulk: one certificate per CSV row (Node)

Renders run one request per PDF. This loop goes through a CSV sequentially, which stays inside every plan's parallel-render limit, and backs off on 429 concurrency_limit or 503 busy. It stops on 402 quota_exceeded so you can upgrade before the rest of the batch.

certificates.mjs
// node certificates.mjs attendees.csv
// attendees.csv:
// name,email,id
// Ayesha Khan,ayesha@example.com,CERT-7F3K-21
import { readFile, writeFile, mkdir } from 'node:fs/promises';

const [header, ...lines] = (await readFile(process.argv[2], 'utf8')).trim().split(/\r?\n/);
const cols = header.split(',').map((c) => c.trim());
await mkdir('certificates', { recursive: true });
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

for (const line of lines) {
  // Simple CSV: no commas inside values. Use a CSV parser for anything else.
  const row = Object.fromEntries(line.split(',').map((v, i) => [cols[i], v.trim()]));
  const body = {
    template_id: 'gallery:certificate',
    filename: `${row.id}.pdf`,
    data: {
      recipient: row.name,
      course: 'Practical Machine Learning',
      hours: 24,
      date: '2026-10-15',
      certificate_id: row.id,
      instructor: 'Dr. Omar Siddiqui',
      organization: 'Northwind Academy',
      verify_url: `https://example.com/verify/${row.id}`,
    },
  };
  for (let attempt = 1; ; attempt++) {
    const res = await fetch('https://YOUR-DOMAIN/v1/render', {
      method: 'POST',
      headers: { Authorization: `Bearer ${process.env.DOCFORGE_KEY}`, 'Content-Type': 'application/json' },
      body: JSON.stringify(body),
    });
    if ((res.status === 429 || res.status === 503) && attempt < 6) {
      await sleep(Number(res.headers.get('retry-after') || 2) * 1000);
      continue;
    }
    if (!res.ok) {
      const err = await res.json().catch(() => ({}));
      console.error(row.id, res.status, err.error, err.message ?? '');
      if (res.status === 402) process.exit(1); // out of renders: upgrade, then re-run the rest
      break;
    }
    await writeFile(`certificates/${row.id}.pdf`, Buffer.from(await res.arrayBuffer()));
    console.log('ok', row.id, 'renders left:', res.headers.get('x-renders-remaining'));
    break;
  }
}

Emailing them? Add "output": "url" and put the 24-hour link in your email instead of attaching the file.

Customising the layout

Copy the template into your account and edit it there; your app keeps sending only data:

curl https://YOUR-DOMAIN/v1/templates \
  -H "Authorization: Bearer $DOCFORGE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"from_gallery": "certificate", "name": "My certificate"}'
# -> {"id": "...", "name": "...", "html": "...", "css": "...", ...}
# then render with {"template_id": "<that id>", "data": {...}}

Stored templates keep HTML, CSS and sample data. Page options such as footer_html or landscape travel with each render request in options. Helpers are listed in the template language docs.
