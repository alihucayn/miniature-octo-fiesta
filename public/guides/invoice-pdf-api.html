Invoice PDF API: JSON in, invoice PDF out

Send your invoice as JSON to POST /v1/render with "template_id": "gallery:invoice" and get back a print-ready A4 PDF. No HTML to write, no headless browser to run.

Invoice with line items, discount, shipping, one tax rate or several tax lines, and page numbers. Pass "total" to print your billing system's figure. The template formats money with your currency and locale, prints "Page X of Y" on every page, and keeps line rows and the totals block from splitting across pages.

Fields

FieldMeaning
number, issue_date, due_dateInvoice number and dates. Dates accept ISO strings, epoch milliseconds or epoch seconds.
currency, localeISO currency (any case) and a BCP 47 locale such as en-US, de-DE or ur-PK.
company {name, address, email, logo_url}Your business. logo_url must be https (or a data: URI).
client {name, address, email}Who you are billing.
items [{description, qty, price}]Line items. price is in major units (12.50, not 1250).
discount, shippingOptional amounts. Discount is subtracted before tax.
tax_rate or tax_lines [{name, rate, amount}]One percentage, or several precomputed lines (e.g. GST + PST).
totalOptional. Pass your billing system's figure and it is printed as-is instead of being recomputed.
notes, payment_instructions, accent_colorFree text and the brand colour.

Render it with curl

With no data, the API renders the sample above and sets X-DocForge-Sample-Data: true, which is a quick way to check your key:

Sample data
curl https://YOUR-DOMAIN/v1/render \
  -H "Authorization: Bearer $DOCFORGE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"template_id": "gallery:invoice"}' \
  -o invoice.pdf

With your own data, save the JSON above as sample.json and wrap it:

Your data
jq '{template_id: "gallery:invoice", filename: "invoice.pdf", data: .}' sample.json \
  | curl https://YOUR-DOMAIN/v1/render \
      -H "Authorization: Bearer $DOCFORGE_KEY" \
      -H "Content-Type: application/json" \
      --data-binary @- -o invoice.pdf -D headers.txt
grep -i x-renders-remaining headers.txt

Node.js

invoice.mjs
// Node 18+ (built-in fetch). npm i nothing.
import { writeFile } from 'node:fs/promises';

export async function renderInvoice(invoice) {
  const res = await fetch('https://YOUR-DOMAIN/v1/render', {
    method: 'POST',
    headers: { Authorization: `Bearer ${process.env.DOCFORGE_KEY}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ template_id: 'gallery:invoice', filename: `${invoice.number}.pdf`, data: invoice }),
    signal: AbortSignal.timeout(40_000),
  });
  if (!res.ok) {
    const err = await res.json().catch(() => ({}));
    // 402 quota_exceeded -> err.upgrade_url, 422 template_error -> err.message,
    // 429 concurrency_limit / 503 busy -> retry after the Retry-After header.
    throw new Error(`DocForge ${res.status} ${err.error}: ${err.message ?? ''}`);
  }
  console.log('renders left this month:', res.headers.get('x-renders-remaining'));
  const pdf = Buffer.from(await res.arrayBuffer());
  await writeFile(`${invoice.number}.pdf`, pdf);
  return pdf;
}

Python

invoice.py
import os
import requests

def render_invoice(invoice: dict) -> bytes:
    r = requests.post(
        "https://YOUR-DOMAIN/v1/render",
        headers={"Authorization": f"Bearer {os.environ['DOCFORGE_KEY']}"},
        json={"template_id": "gallery:invoice", "filename": f"{invoice['number']}.pdf", "data": invoice},
        timeout=40,
    )
    if not r.ok:
        err = r.json()
        # err["error"] is a stable code: quota_exceeded, template_error, busy, ...
        raise RuntimeError(f"DocForge {r.status_code} {err.get('error')}: {err.get('message', '')}")
    with open(f"{invoice['number']}.pdf", "wb") as f:
        f.write(r.content)
    return r.content

<?php
// composer require guzzlehttp/guzzle

$res = $client->post('/v1/render', [
    'headers' => ['Authorization' => 'Bearer ' . getenv('DOCFORGE_KEY')],

        'filename' => $invoice['number'] . '.pdf',

    ],
    'http_errors' => false,
]);

if ($res->getStatusCode() !== 200) {
    $err = json_decode((string) $res->getBody(), true);
    throw new RuntimeException("DocForge {$res->getStatusCode()} {$err['error']}: " . ($err['message'] ?? ''));
}
file_put_contents($invoice['number'] . '.pdf', (string) $res->getBody());

Page numbers, tax and totals

The invoice ships with a default options.footer_html that prints "Page X of Y". Replace it by sending your own options.footer_html (Chromium fills <span class="pageNumber"> and <span class="totalPages">). For other paper sizes pass "options": {"format": "letter"}; accepted formats are a4, letter, legal, a5, a3, tabloid and ledger.

Getting a link instead of a file

Add "output": "url" and the response is JSON: {url, filename, size, expires_at, content_type}. The link works for 24 hours without a key, which is what Zapier, Make and n8n need to attach the PDF to an email. "output": "base64" returns the file inline in JSON. See the no-code recipes.

Customising the layout

Copy the template into your account and edit it there; your app keeps sending only data:

curl https://YOUR-DOMAIN/v1/templates \
  -H "Authorization: Bearer $DOCFORGE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"from_gallery": "invoice", "name": "My invoice"}'
# -> {"id": "...", "name": "...", "html": "...", "css": "...", ...}
# then render with {"template_id": "<that id>", "data": {...}}

Stored templates keep HTML, CSS and sample data. Page options such as footer_html or landscape travel with each render request in options. Helpers are listed in the template language docs.
