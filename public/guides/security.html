Security

How DocForge handles your templates, data and API keys. This page describes what the code does today; it is not a certification.

Rendering isolation

  • Every render gets a fresh, isolated browser context in headless Chromium, closed when the PDF is done. No cookies, storage or cache are shared between renders or customers.
  • JavaScript is disabled in that context, so a template or injected value cannot run scripts.
  • Template values are HTML-escaped by default (Handlebars {{ }}).
  • Every render has a deadline (30 seconds by default), templates that take too long to evaluate are stopped, and each plan has a page limit, so one document cannot tie up the service.

Network access from templates

  • Remote assets are fetched only over https, and only images, fonts and stylesheets. Scripts, frames and other requests are blocked.
  • Hostnames are resolved and requests to private, loopback, link-local and other internal addresses are refused, including IPv6 and IPv4-mapped forms. This protects the server's metadata service and internal network.
  • The response header X-DocForge-Blocked-Assets tells you how many requests were blocked. See remote assets.

API keys

  • Keys are stored only as a SHA-256 hash; the plain key is shown once at creation.
  • Rotate a key at any time with POST /v1/keys/rotate; the old key stops working immediately.
  • Lost keys are recovered with a single-use link, valid for 30 minutes, sent to the account email.

Data handling

  • Render payloads and PDFs are processed in memory and not retained, unless you request output: "url", whose files are deleted after 24 hours. Details in the privacy policy.
  • All traffic to the API is served over HTTPS.
  • The account database is backed up daily; snapshots are kept for 7 days on the server and 7 days off-site.
  • Card payments are handled entirely by Lemon Squeezy. DocForge never sees card numbers.

Reporting a vulnerability

Email with the details and steps to reproduce. Please give us reasonable time to fix the issue before disclosing it. We do not run a paid bug bounty.
