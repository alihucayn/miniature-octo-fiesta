What we do not keep

The JSON or HTML you send to /v1/render and the PDFs we produce are processed in memory and not retained. The exception is opt-in: with "output": "url" the PDF is written to disk so the download link works, and it is deleted after 24 hours. Anyone with that link can download the file until then, so treat it like a password. The public demo works the same way and stores nothing.

Event and error logs record the time, account id, route, status or error code and a request id. Account-email events log a masked recipient address (for example a***@example.com) and the subject. Logs never contain request bodies or rendered PDFs. They are rotated by size (5 files of 10 MB) and typically kept for [TODO: retention, e.g. about 14 days].

Backups

The account database is snapshotted daily. Snapshots are kept for 7 days on the server and for 7 days in encrypted off-site storage, so deleted data disappears from all backups within a week.
