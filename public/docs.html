API reference

Base URL: your DocForge domain. All requests and responses are JSON unless noted. Authenticate with Authorization: Bearer df_live_….

Quick start

curl -X POST https://YOUR-DOMAIN/v1/signup -H "Content-Type: application/json" -d '{"email":"you@company.com"}'
# → {"api_key":"df_live_…"}

curl -X POST https://YOUR-DOMAIN/v1/render \
  -H "Authorization: Bearer df_live_…" -H "Content-Type: application/json" \
  -d '{"template_id":"gallery:receipt"}' -o receipt.pdf

Node.js

const res = await fetch('https://YOUR-DOMAIN/v1/render', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.DOCFORGE_KEY}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({ template_id: 'tpl_abc123', data: order }),
});
const pdf = Buffer.from(await res.arrayBuffer());

Python

import requests
pdf = requests.post("https://YOUR-DOMAIN/v1/render",
    headers={"Authorization": f"Bearer {KEY}"},
    json={"template_id": "gallery:invoice", "data": invoice}).content

POST /v1/render

FieldDescription
template_idA stored template (tpl_…) or a gallery template (gallery:invoice, gallery:receipt, gallery:certificate, gallery:quote, gallery:packing-slip).
html, cssInline Handlebars template, instead of template_id.
dataObject passed to the template. Defaults to the template's sample data.
optionsformat (A4, Letter, Legal, A5, A3), landscape, margin ({top,right,bottom,left} as CSS lengths), printBackground (default true), preferCSSPageSize.
output"pdf" (default, binary body) or "base64" (JSON with a base64 field, handy in Zapier/Make).
filenameUsed in Content-Disposition.

Response header X-Renders-Remaining shows this month's remaining quota. Failed renders are not counted.

Templates

GET /v1/templatesList your templates.
POST /v1/templates{"name","html","css","sample_data"}, or {"from_gallery":"invoice"} to copy a starter.
GET /v1/templates/:idFetch one, including HTML.
PUT /v1/templates/:idUpdate any subset of fields.
DELETE /v1/templates/:idDelete.
GET /v1/galleryBuilt-in templates with sample data (no auth).

Template language

Templates are Handlebars: {{name}}, {{#each items}}…{{/each}}, {{#if paid}}…{{/if}}. Values are HTML-escaped. Built-in helpers:

{{money amount "EUR" "de-DE"}}Currency formatting (currency and locale optional).
{{date issued "long"}}Date formatting: short, medium (default), long, full.
{{sum items "qty" "price"}}Sum of qty×price over a list. With one field, sums that field.
add, sub, mul, div, percent, fixedArithmetic, e.g. {{money (mul qty price) ../currency}}.
eq, gt, default, upper, lower, incComparisons and string helpers. {{inc @index}} gives 1-based row numbers.

A data field named like a helper (e.g. date) is shadowed by the helper when written alone; use {{this.date}} to read the field.

Images and fonts load over https:// or as data: URIs. JavaScript inside templates is disabled.

Account & billing

GET /v1/mePlan, usage this month and limits.
POST /v1/keys/rotateIssue a new key and revoke the old one.
GET /v1/billing/checkout?plan=starterReturns a checkout URL tied to your account (starter, pro, business).
GET /v1/plansPlans and limits.

Errors

400Invalid input (invalid_json, missing_template, invalid_template)
401Missing or invalid API key
402quota_exceeded or template_limit: upgrade your plan
404Template not found
422template_error: Handlebars syntax error, message points at the line
429Rate limited
